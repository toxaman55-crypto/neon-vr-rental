# NEONVR

A multilingual website for VR events in Tallinn.

## Development

Requires Node.js and npm.

```bash
npm ci
npm run dev
```

Open http://localhost:3000 to view the site.

## Checks

```bash
npm run lint
npm run build
```

## Booking

Online booking is currently disabled. The calendar and request form do not accept or send
personal information. Connect and verify a booking service before enabling them.
